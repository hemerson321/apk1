COMO GERAR O APK ONLINE SEM ANDROID STUDIO

1. Crie um repositório no GitHub.
2. Envie todos os arquivos deste projeto para o repositório.
3. No GitHub, abra a aba Actions.
4. Clique em Build APK.
5. Clique em Run workflow.
6. Quando terminar, abra a execução e baixe o arquivo em Artifacts:
   GeratecGoldWebView-debug-apk

Dentro do ZIP baixado estará o APK debug pronto para instalar no Android.

URL configurada no app:
https://server.geratec.com.br/itinerarios/gold/
